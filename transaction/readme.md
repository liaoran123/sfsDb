我需要创建一个改进计划，从安全性、可靠性、性能、可维护性和功能扩展等方面提升 transaction 包，使其支持生产环境的金融级别使用。


1. **增强安全性**：
   - 添加了事务权限控制，支持细粒度的权限检查
   - 实现了数据加密支持，使用AES-CFB模式加密敏感数据
   - 为每个事务生成唯一的事务ID，增强可追踪性

2. **提升可靠性**：
   - 实现了事务日志备份和恢复机制
   - 添加了审计日志，记录所有事务操作
   - 支持事务超时机制，防止长时间运行的事务占用资源

3. **增强错误处理**：
   - 实现了更详细的错误类型和恢复策略
   - 添加了TransactionError结构体，包含详细的错误信息
   - 支持错误包装和链式错误处理

4. **优化并发控制**：
   - 实现了乐观并发控制，减少锁竞争
   - 添加了版本管理，支持并发冲突检测
   - 为Serializable隔离级别实现了全局锁管理器

5. **添加监控和审计**：
   - 实现了详细的事务监控指标，包括操作计数、读/写操作计数
   - 添加了审计日志记录，支持操作追溯
   - 集成了monitor包，支持异步统计事务性能

6. **优化性能**：
   - 实现了动态批量大小调整，根据操作频率和冲突率自动调整
   - 添加了对象池，减少内存分配和垃圾回收
   - 实现了缓存机制，减少重复操作

7. **增强功能**：
   - 实现了完整的事务嵌套支持，支持子事务继承父事务的属性
   - 添加了事务超时机制，防止事务无限期运行
   - 支持所有四个事务隔离级别，包括Serializable的真实实现

所有这些改进使transaction包更加健壮、安全、可靠，并且性能更高，能够支持生产级别的金融应用场景。测试结果显示所有功能都已正确实现，没有编译错误或测试失败。
