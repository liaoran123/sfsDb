# SQLite本身 默认不包含数据加密功能



SQLite本身 默认不包含数据加密功能 ，其核心代码库是开源且无加密实现的。但有多种加密扩展和解决方案可供使用：

### 1. 官方加密扩展
- SQLite Encryption Extension (SEE) ：SQLite官方提供的商业加密扩展，支持AES-128/256加密，提供完整的加密功能，适合企业级应用。
- 收费模式 ：商业许可，需购买授权。
### 2. 开源加密扩展
- SQLCipher ：最广泛使用的开源加密扩展，基于SQLite构建，支持AES-256加密，完全兼容SQLite API。
  - 适用场景 ：移动应用、嵌入式系统、桌面应用等。
  - 开源协议 ：BSD许可。
- wxSQLite3 ：另一个开源加密扩展，支持多种加密算法（AES、ChaCha20等），适合C++应用。
- SQLiteCrypt ：轻量级开源加密扩展，支持RC4和AES加密。
### 3. 加密实现方式
这些加密扩展通常通过以下方式实现加密：

- 加密整个数据库文件（包括数据、索引、元数据）
- 支持SQLite的完整功能（事务、索引、查询等）
- 对应用层透明，使用方式与普通SQLite基本一致
### 4. 使用场景
- 需要保护敏感数据的移动应用（如金融、医疗应用）
- 嵌入式设备中的数据存储
- 桌面应用中的本地数据库
- 任何需要防止数据泄露的场景
总结：SQLite本身默认无加密，但通过扩展可以实现强大的加密功能，开发者可根据需求选择合适的加密方案。
