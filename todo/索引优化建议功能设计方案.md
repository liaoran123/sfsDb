# 索引优化建议功能设计方案

## 一、概述

### 1.1 项目背景

sfsDb是一个轻量级嵌入式关系型数据库，专注于提供高性能、灵活的存储解决方案。系统的一个重要特点是**不支持无索引搜索**，所有查询都必须基于索引进行。这意味着索引的设计和优化对系统性能至关重要。

目前，sfsDb缺少索引优化建议功能，无法为用户提供索引设计、使用和优化方面的指导，限制了用户对数据库性能的优化能力。

### 1.2 设计目标

- 提供全面的索引优化建议，帮助用户创建高效的索引
- 支持冗余索引检测，避免不必要的索引开销
- 分析索引使用情况，识别低效索引
- 为慢查询提供索引优化建议
- 确保索引优化建议功能不会显著降低数据库性能
- 提供简单易用的API接口，方便用户获取索引优化建议

## 二、功能需求

### 2.1 核心功能列表

| 功能点 | 描述 | 实现优先级 |
|--------|------|------------|
| 冗余索引检测 | 检测表中冗余的索引，避免不必要的索引开销 | 高 |
| 索引使用情况分析 | 分析索引的使用频率、扫描行数等指标 | 高 |
| 索引优化建议 | 基于查询模式和数据分布，提供索引设计建议 | 中 |
| 慢查询索引建议 | 为慢查询提供具体的索引优化建议 | 高 |

### 2.2 详细功能描述

#### 2.2.1 冗余索引检测

- **功能描述**：检测表中冗余的索引，包括：
  - 完全冗余的索引（索引字段和顺序完全相同）
  - 部分冗余的索引（一个索引是另一个索引的前缀）
  - 功能冗余的索引（多个索引实现相同的查询功能）

- **检测算法**：
  1. 收集表的所有索引信息
  2. 分析索引字段的组合和顺序
  3. 检测完全相同的索引
  4. 检测前缀冗余的索引
  5. 生成冗余索引报告

#### 2.2.2 索引使用情况分析

- **功能描述**：分析索引的使用情况，包括：
  - 索引命中次数
  - 索引扫描行数
  - 索引使用率
  - 索引覆盖情况

- **收集方式**：
  - 实时记录索引查询信息
  - 定期分析索引使用情况
  - 支持配置采样率，减少性能开销

#### 2.2.3 索引优化建议

- **功能描述**：基于查询模式和数据分布，提供索引设计建议，包括：
  - 建议创建的索引
  - 建议删除的索引
  - 索引字段顺序建议
  - 复合索引设计建议

- **分析算法**：
  1. 分析查询模式，识别频繁使用的字段组合
  2. 分析数据分布，识别高选择性字段
  3. 考虑索引覆盖情况
  4. 生成索引优化建议

#### 2.2.4 慢查询索引建议

- **功能描述**：为慢查询提供具体的索引优化建议，包括：
  - 识别慢查询中使用的字段
  - 建议创建的索引
  - 分析现有索引的使用情况
  - 提供具体的优化建议

- **实现方式**：
  1. 收集慢查询信息
  2. 分析慢查询的查询条件和字段
  3. 检查现有索引是否覆盖查询
  4. 生成针对性的索引建议

## 三、架构设计

### 3.1 整体架构

索引优化建议功能将作为sfsDb的一个模块，位于`engine层`，与现有的统计信息模块协同工作。

```
┌─────────────────┐
│    API层        │ ← 提供索引优化建议查询接口
└─────────────────┘
        ▲
        │
┌─────────────────┐
│    engine层     │
│  ┌───────────┐  │
│  │ 索引优化建议模块 │  │ ← 新增模块
│  └───────────┘  │
│  ┌───────────┐  │
│  │ 统计信息模块 │  │ ← 复用现有模块
│  └───────────┘  │
│  ┌───────────┐  │
│  │ 索引管理模块 │  │ ← 复用现有模块
│  └───────────┘  │
└─────────────────┘
        ▲
        │
┌─────────────────┐
│    storage层    │ ← 存储索引优化相关数据
└─────────────────┘
```

### 3.2 模块划分

索引优化建议模块将划分为以下子模块：

1. **索引分析器**：负责分析索引的使用情况和性能
2. **冗余索引检测器**：负责检测冗余索引
3. **索引建议生成器**：负责生成索引优化建议
4. **慢查询分析器**：负责分析慢查询并提供索引建议
5. **API模块**：负责提供索引优化建议查询接口
6. **配置模块**：负责管理索引优化建议功能的配置

### 4.2 核心算法设计

#### 4.2.1 冗余索引检测算法

```go
// DetectRedundantIndexes 检测冗余索引
func DetectRedundantIndexes(table *Table) ([]string, error) {
    var redundantIndexes []string
    
    // 获取表的所有索引
    indexes := table.indexs.GetAllIndexes()
    
    // 比较每个索引与其他索引
    for i, index1 := range indexes {
        fields1 := index1.GetFields()
        for j := i + 1; j < len(indexes); j++ {
            index2 := indexes[j]
            fields2 := index2.GetFields()
            
            // 检测完全相同的索引
            if reflect.DeepEqual(fields1, fields2) {
                redundantIndexes = append(redundantIndexes, index2.Name())
                continue
            }
            
            // 检测前缀冗余的索引
            if isPrefixOf(fields1, fields2) || isPrefixOf(fields2, fields1) {
                // 选择使用频率较低的索引作为冗余索引
                if getIndexUsage(index1.Name()) < getIndexUsage(index2.Name()) {
                    redundantIndexes = append(redundantIndexes, index1.Name())
                } else {
                    redundantIndexes = append(redundantIndexes, index2.Name())
                }
            }
        }
    }
    
    return redundantIndexes, nil
}

// isPrefixOf 判断slice1是否是slice2的前缀
func isPrefixOf(slice1, slice2 []string) bool {
    if len(slice1) >= len(slice2) {
        return false
    }
    for i, v := range slice1 {
        if v != slice2[i] {
            return false
        }
    }
    return true
}
```

#### 4.2.2 索引建议生成算法

```go
// GenerateIndexSuggestions 生成索引建议
func GenerateIndexSuggestions(table *Table) ([]IndexSuggestion, error) {
    var suggestions []IndexSuggestion
    
    // 获取表的查询模式
    queryPatterns := getQueryPatterns(table.Name())
    
    // 获取表的现有索引
    existingIndexes := table.indexs.GetAllIndexes()
    
    // 分析查询模式，生成索引建议
    for _, pattern := range queryPatterns {
        // 检查现有索引是否覆盖该查询模式
        if !isQueryCoveredByIndexes(pattern, existingIndexes) {
            // 生成索引建议
            suggestion := IndexSuggestion{
                Type:       "CREATE",
                TableName:  table.Name(),
                IndexName:  generateIndexName(pattern),
                Fields:     pattern.Fields,
                IndexType:  "normal",
                Reason:     fmt.Sprintf("查询模式 %v 没有被现有索引覆盖", pattern.Fields),
                Priority:   getPriority(pattern),
            }
            suggestions = append(suggestions, suggestion)
        }
    }
    
    // 检测并建议删除冗余索引
    redundantIndexes, err := DetectRedundantIndexes(table)
    if err != nil {
        return nil, err
    }
    
    for _, indexName := range redundantIndexes {
        suggestion := IndexSuggestion{
            Type:       "DROP",
            TableName:  table.Name(),
            IndexName:  indexName,
            Fields:     []string{},
            IndexType:  "",
            Reason:     "该索引是冗余的，建议删除",
            Priority:   "MEDIUM",
        }
        suggestions = append(suggestions, suggestion)
    }
    
    return suggestions, nil
}
```

- 帮助用户创建高效的索引，提高查询性能
