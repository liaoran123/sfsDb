# SFSDB 示例

本目录包含SFSDB数据库引擎的使用示例。

## 示例文件

### 1. basic.go - 基础示例
展示SFSDB的基本功能：
- 数据库初始化
- 创建表和设置字段
- 创建主键索引
- 插入数据
- 查询所有数据
- 条件查询
- 更新数据
- 删除数据
- 使用二级索引查询

### 2. advanced.go - 高级示例
展示SFSDB的高级功能：
- 使用组合主键
- 创建全文索引
- 组合主键查询
- 全文搜索
- 批量操作
- 范围查询

## 如何运行示例

### 1. 确保Go环境已配置
```bash
go version
```

### 2. 运行基础示例
```bash
cd examples
go run basic.go
```

### 3. 运行高级示例
```bash
cd examples
go run advanced.go
```

## 输出说明

运行示例后，您将看到以下内容：
- 数据库初始化信息
- 表创建和字段设置过程
- 数据插入结果
- 查询结果
- 更新和删除操作的结果
- 高级功能的使用示例

## 注意事项

1. 示例运行后会在当前目录创建数据库文件：
   - `example_db` - 基础示例的数据库
   - `advanced_example_db` - 高级示例的数据库

2. 您可以在运行示例后查看这些目录的内容，了解SFSDB如何存储数据。

3. 如果您想重新运行示例，建议先删除这些数据库目录，以避免数据冲突。

4. 示例代码包含详细的注释，您可以通过阅读代码了解SFSDB的使用方法。
