## 6.1 事务概述

事务是确保数据一致性和完整性的关键机制。sfsDb 提供了 `transactionLockFree` 包，基于乐观并发控制（OCC）实现高性能无锁事务系统。

### 为什么需要事务？

在并发场景下，多个操作同时修改数据时，如果没有事务保护，可能会出现：

1. **数据不一致**：部分操作成功，部分失败
2. **脏读**：读取到未提交的数据
3. **不可重复读**：同一事务内两次读取结果不同
4. **幻读**：同一事务内两次查询结果数量不同

sfsDb 的无锁事务系统完美解决了这些问题。

## 6.2 无锁事务系统原理

### 6.2.1 乐观并发控制（OCC）

传统数据库使用锁机制来防止并发冲突，但锁会降低并发性能。sfsDb 采用乐观并发控制：

**核心思想**：
- 假设冲突很少发生
- 事务执行时不加锁
- 提交时检查是否有冲突
- 如果有冲突，回滚并重试

### 6.2.2 版本管理器

让我们查看项目中的实际代码（来自 `transactionLockFree/occ.go`）：

```go
// LockFreeVersionManager 版本管理器（使用互斥锁实现）
type LockFreeVersionManager struct {
    versions map[string]uint64 // 键 -> 版本号
    mu       sync.RWMutex      // 读写锁
    initOnce sync.Once         // 仅用于初始化
}

// GetVersion 获取版本号
func (vm *LockFreeVersionManager) GetVersion(key string) uint64 {
    vm.init()
    vm.mu.RLock()
    defer vm.mu.RUnlock()
    
    if version, exists := vm.versions[key]; exists {
        return version
    }
    return 0
}

// IncrementVersion 递增版本号
func (vm *LockFreeVersionManager) IncrementVersion(key string) uint64 {
    vm.init()
    vm.mu.Lock()
    defer vm.mu.Unlock()
    
    currentVersion := vm.versions[key]
    newVersion := currentVersion + 1
    vm.versions[key] = newVersion
    return newVersion
}

// CheckConflict 检查冲突
func (vm *LockFreeVersionManager) CheckConflict(key string, expectedVersion uint64) bool {
    vm.init()
    vm.mu.RLock()
    defer vm.mu.RUnlock()
    
    currentVersion := vm.versions[key]
    return currentVersion != expectedVersion
}
```

**工作原理**：
1. 每个数据键都有一个版本号
2. 读取数据时记录当前版本号
3. 写入数据前检查版本号是否变化
4. 如果版本号变化，说明有冲突

## 6.3 完整的可运行示例

```go
package main

import (
	"fmt"
	"log"

	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/storage"
	"github.com/liaoran123/sfsDb/transactionLockFree"
)

func main() {
	fmt.Println("=== 第 6 章：事务处理示例 ===\n")

	// 示例 1：基本事务操作
	fmt.Println("--- 示例 1：基本事务操作 ---")
	basicTransactionExample()
	fmt.Println()

	fmt.Println("=== 所有示例执行完成 ===")
}

// basicTransactionExample 演示基本的事务操作
func basicTransactionExample() {
	// 创建用户表
	userTable, err := engine.TableNew("example_users")
	if err != nil {
		log.Fatalf("创建用户表失败: %v", err)
	}

	// 设置表字段
	fields := map[string]any{"id": 0, "name": "", "age": 0, "balance": 0}
	err = userTable.SetFields(fields)
	if err != nil {
		log.Fatalf("设置表字段失败: %v", err)
	}

	// 场景 1：创建事务并插入数据
	fmt.Println("1. 创建事务并插入数据")
	tx, err := transactionLockFree.NewTableTransaction(userTable)
	if err != nil {
		log.Fatalf("创建事务失败: %v", err)
	}

	// 插入用户 1
	user1 := map[string]interface{}{"id": 1, "name": "Alice", "age": 25, "balance": 1000}
	id1, err := tx.Insert(&user1)
	if err != nil {
		log.Fatalf("插入用户1失败: %v", err)
	}
	fmt.Printf("   插入用户1成功, ID: %d\n", id1)

	// 提交事务
	err = tx.Commit()
	if err != nil {
		log.Fatalf("提交事务失败: %v", err)
	}
	fmt.Println("   事务提交成功")

	// 场景 2：回滚演示
	fmt.Println("\n2. 回滚演示")
	tx3, err := transactionLockFree.NewTableTransaction(userTable)
	if err != nil {
		log.Fatalf("创建事务失败: %v", err)
	}

	// 插入用户3（不会被保存）
	user3 := map[string]interface{}{"id": 3, "name": "Charlie", "age": 35, "balance": 2000}
	id3, err := tx3.Insert(&user3)
	if err != nil {
		log.Fatalf("插入用户3失败: %v", err)
	}
	fmt.Printf("   插入用户3成功, ID: %d\n", id3)

	// 回滚事务
	err = tx3.Rollback()
	if err != nil {
		log.Fatalf("回滚事务失败: %v", err)
	}
	fmt.Println("   事务回滚成功（用户3不会被保存）")
}
```

## 6.4 事务基本操作

### 6.4.1 事务接口定义

让我们查看项目中的事务接口（来自 `transactionLockFree/transaction.go`）：

```go
// Transaction 定义事务接口
type Transaction interface {
    // Get 从事务中获取值
    Get(key []byte) ([]byte, error)
    // Put 向事务中设置值
    Put(key []byte, value []byte)
    // Delete 从事务中删除值
    Delete(key []byte)
    // Commit 提交事务
    Commit() error
    // Rollback 回滚事务
    Rollback() error
    // BeginNested 创建一个嵌套事务
    BeginNested() (Transaction, error)
    // GetOptions 获取事务选项
    GetOptions() *TransactionOptions
    // GetTxID 获取事务ID
    GetTxID() uint64
}

// TableTransactionInterface 定义表事务接口
type TableTransactionInterface interface {
    // Insert 在事务中插入记录
    Insert(fields *map[string]interface{}) (int, error)
    // Update 在事务中更新记录
    Update(fields *map[string]interface{}) error
    // Delete 在事务中删除记录
    Delete(fields *map[string]interface{}) error
    // Read 在事务中读取单条记录
    Read(fields *map[string]any) ([]byte, error)
    // Search 在事务中搜索记录
    Search(fields *map[string]any, ops ...util.ComparisonOperator) (*engine.TableIter, error)
    // Commit 提交事务
    Commit() error
    // Rollback 回滚事务
    Rollback() error
    // BeginNested 创建一个嵌套事务
    BeginNested() (TableTransactionInterface, error)
}
```
