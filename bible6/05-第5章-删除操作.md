# 第5章 删除操作

删除操作是数据库CRUD操作中的重要组成部分，sfsDb提供了多种删除记录的方法，包括删除单条记录、删除表中所有记录以及通过迭代器删除符合条件的记录。本章将详细介绍这些删除操作的实现和使用方法。

## 5.1 删除单条记录

### 5.1.1 函数签名

```go
func (t *Table) Delete(fields *map[string]any, batchs ...storage.Batch) error
```

### 5.1.2 参数说明

- `fields *map[string]any` - 主键值，可能是组合主键
- `batchs ...storage.Batch` - 批量操作对象，支持乐观锁

### 5.1.3 实现原理

删除单条记录的实现流程如下：

1. 创建DeleteImpl实例
2. 检查是否包含主键
3. 准备批量操作
4. 读取记录
5. 删除记录
6. 提交事务

### 5.1.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 准备删除条件（主键）
	id := 1
	fields := map[string]any{
		"id": id,
	}

	// 执行删除操作
	err = table.Delete(&fields)
	if err != nil {
		fmt.Println("删除记录失败:", err)
		return
	}

	fmt.Printf("删除ID为%d的记录成功\n", id)
}
```

## 5.2 删除表中所有记录

### 5.2.1 函数签名

```go
func (t *Table) DeleteAll() error
```

### 5.2.2 实现原理

删除表中所有记录的实现流程如下：

1. 获取表的所有kv键值对迭代器
2. 创建批量操作对象
3. 定义批量操作的大小限制（1000）
4. 遍历并删除所有键值对
5. 当批量操作的大小达到限制时，执行批量操作并重置批量操作对象
6. 执行剩余的批量操作

### 5.2.3 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 执行删除所有记录操作
	err = table.DeleteAll()
	if err != nil {
		fmt.Println("删除所有记录失败:", err)
		return
	}

	fmt.Println("删除表中所有记录成功")
}
```

## 5.3 通过迭代器删除记录

### 5.3.1 函数签名

```go
func (t *TableIter) Delete(limit ...int) error
```

### 5.3.2 参数说明

- `limit ...int` - 可选参数，限制删除记录的数量

### 5.3.3 实现原理

通过迭代器删除记录的实现流程如下：

1. 获取批量操作对象
2. 遍历迭代器中的记录
3. 将记录转换为map[string]any并调用Table.Delete
4. 统计删除成功的记录数
5. 执行批量操作

### 5.3.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/engine/record"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 创建查询条件
	query := record.NewQuery()
	query.GreaterThan("age", 30) // 删除年龄大于30的记录

	// 获取迭代器
	iter := table.Where(query)
	defer iter.Release()

	// 执行删除操作，限制删除10条记录
	err = iter.Delete(10)
	if err != nil {
		fmt.Println("删除记录失败:", err)
		return
	}

	fmt.Println("删除符合条件的记录成功")
}
```

## 5.4 内部实现细节

### 5.4.1 DeleteImpl结构

`Delete` 方法内部使用 `DeleteImpl` 结构来处理删除操作，它负责：

- 检查主键
- 准备批量操作
- 读取记录
- 删除记录
- 提交事务

### 5.4.2 批量操作优化

删除操作使用批量操作来提高性能，特别是 `DeleteAll` 方法，它会：

- 每1000条记录执行一次批量操作
- 减少磁盘I/O操作
- 提高删除效率

### 5.4.3 错误处理

删除操作的错误处理包括：

- 检查主键是否存在
- 处理记录不存在的情况
- 确保批量操作的正确执行

## 5.5 性能优化建议

1. **使用批量操作**：当删除多条记录时，使用迭代器的 `Delete` 方法可以批量处理，提高性能
2. **设置合理的批量大小**：默认批量大小为1000，可以根据实际情况调整
3. **避免全表删除**：`DeleteAll` 会删除表中所有记录，使用时需谨慎
4. **使用索引**：删除操作会涉及索引的更新，确保索引设计合理

## 5.6 注意事项

1. **主键必须提供**：删除操作必须提供主键值
2. **记录不存在的处理**：当删除不存在的记录时，会返回"记录不存在"的错误
3. **事务处理**：删除操作会在事务中执行，确保数据一致性
4. **索引更新**：删除记录时会自动更新相关索引

## 5.7 完整示例

以下是一个完整的删除操作示例，展示了如何使用各种删除方法：

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/engine/record"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 1. 删除单条记录
	fmt.Println("=== 删除单条记录 ===")
	id := 1
	fields := map[string]any{
		"id": id,
	}
	err = table.Delete(&fields)
	if err != nil {
		fmt.Println("删除记录失败:", err)
	} else {
		fmt.Printf("删除ID为%d的记录成功\n", id)
	}

	// 2. 通过迭代器删除记录
	fmt.Println("\n=== 通过迭代器删除记录 ===")
	query := record.NewQuery()
	query.LessThan("age", 20) // 删除年龄小于20的记录
	iter := table.Where(query)
	err = iter.Delete(5) // 限制删除5条
	if err != nil {
		fmt.Println("删除记录失败:", err)
	} else {
		fmt.Println("删除符合条件的记录成功")
	}
	iter.Release()

	// 3. 删除表中所有记录（谨慎使用）
	fmt.Println("\n=== 删除表中所有记录 ===")
	// err = table.DeleteAll()
	// if err != nil {
	// 	fmt.Println("删除所有记录失败:", err)
	// } else {
	// 	fmt.Println("删除表中所有记录成功")
	// }
}
```

## 5.8 总结

删除操作是数据库操作中的重要组成部分，sfsDb提供了多种删除方法以满足不同的使用场景：

- `Delete` - 删除单条记录，需要提供主键
- `DeleteAll` - 删除表中所有记录，谨慎使用
- `TableIter.Delete` - 通过迭代器删除符合条件的记录，支持批量操作和数量限制

合理使用这些删除方法，可以有效地管理数据库中的数据，保持数据的准确性和一致性。
