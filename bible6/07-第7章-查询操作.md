# 第7章 查询操作

查询操作是数据库CRUD操作中的重要组成部分，sfsDb提供了多种查询记录的方法，包括按主键查询、范围查询、条件查询等。本章将详细介绍这些查询操作的实现和使用方法。

## 7.1 按主键查询

### 7.1.1 函数签名

```go
func (t *Table) Read(fields *map[string]any) ([]byte, error)
```

### 7.1.2 参数说明

- `fields *map[string]any` - 主键值，可能是组合主键

### 7.1.3 实现原理

按主键查询的实现流程如下：

1. 将字段转换为字节数组
2. 生成主键值
3. 调用ReadByBytes方法读取记录
4. 处理错误情况

### 7.1.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/engine/record"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 准备查询条件（主键）
	id := 1
	fields := map[string]any{
		"id": id,
	}

	// 执行查询操作
	recordBytes, err := table.Read(&fields)
	if err != nil {
		fmt.Println("查询记录失败:", err)
		return
	}

	// 解析记录
	rd, err := record.Unmarshal(recordBytes)
	if err != nil {
		fmt.Println("解析记录失败:", err)
		return
	}

	// 输出记录
	fmt.Printf("查询ID为%d的记录成功: %v\n", id, *rd)
}
```

## 7.2 范围搜索

### 7.2.1 函数签名

```go
func (t *Table) SearchRange(funIter storage.FunIter, Start, Limit *map[string]any) (*TableIter, error)
```

### 7.2.2 参数说明

- `funIter storage.FunIter` - 迭代器函数
- `Start *map[string]any` - 起始条件
- `Limit *map[string]any` - 结束条件

### 7.2.3 实现原理

范围搜索的实现流程如下：

1. 检查参数
2. 匹配索引
3. 生成起始和结束键
4. 创建范围
5. 获取迭代器

### 7.2.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 准备范围搜索条件
	start := map[string]any{
		"age": 20,
	}
	limit := map[string]any{
		"age": 30,
	}

	// 执行范围搜索
	iter, err := table.SearchRange(nil, &start, &limit)
	if err != nil {
		fmt.Println("范围搜索失败:", err)
		return
	}
	defer iter.Release()

	// 遍历结果
	fmt.Println("年龄在20-30之间的用户:")
	for iter.Next() {
		rd := iter.Record()
		fmt.Printf("%v\n", *rd)
	}
}
```

## 7.3 条件搜索

### 7.3.1 函数签名

```go
func (t *Table) Search(fields *map[string]any, ops ...util.ComparisonOperator) (*TableIter, error)
```

### 7.3.2 参数说明

- `fields *map[string]any` - 搜索条件
- `ops ...util.ComparisonOperator` - 比较操作符，默认为Like

### 7.3.3 实现原理

条件搜索的实现流程如下：

1. 检查字段是否存在
2. 匹配索引
3. 生成搜索键
4. 创建范围
5. 获取迭代器
6. 处理不等于操作

### 7.3.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/util"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 准备搜索条件
	fields := map[string]any{
		"name": "张",
	}

	// 执行搜索（前缀匹配）
	iter, err := table.Search(&fields)
	if err != nil {
		fmt.Println("搜索失败:", err)
		return
	}
	defer iter.Release()

	// 遍历结果
	fmt.Println("名字以'张'开头的用户:")
	for iter.Next() {
		rd := iter.Record()
		fmt.Printf("%v\n", *rd)
	}
}
```

## 7.4 遍历表所有数据

### 7.4.1 函数签名

```go
func (t *Table) ForData() *TableIter
```

### 7.4.2 实现原理

遍历表所有数据的实现流程如下：

1. 生成主键前缀
2. 创建范围
3. 获取迭代器
4. 创建TableIter

### 7.4.3 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 获取所有数据的迭代器
	iter := table.ForData()
	defer iter.Release()

	// 遍历所有数据
	fmt.Println("表中所有用户:")
	for iter.Next() {
		rd := iter.Record()
		fmt.Printf("%v\n", *rd)
	}
}
```

## 7.5 内部实现细节

### 7.5.1 索引匹配

查询操作会尝试匹配合适的索引，以提高查询效率：

- `MatchIndexCached` - 缓存的索引匹配
- 支持单字段和组合字段索引

### 7.5.2 范围计算

查询操作使用 `RangeHelper` 来计算搜索范围：

- 支持多种比较操作符
- 处理前缀匹配
- 处理范围查询

### 7.5.3 对象池优化

查询操作使用对象池来提高性能：

- `GlobalFieldsBytesPool` - 字段字节池
- `GlobalTableIterPool` - 表迭代器池

### 7.5.4 错误处理

查询操作的错误处理包括：

- 检查字段是否存在
- 检查索引是否存在
- 处理记录不存在的情况

## 7.6 性能优化建议

1. **使用索引**：确保为常用查询字段创建索引
2. **合理设计主键**：选择合适的主键字段，提高查询效率
3. **使用范围查询**：对于范围查询，使用 `SearchRange` 方法
4. **使用对象池**：sfsDb内部使用对象池优化，避免频繁分配内存
5. **限制结果集**：使用迭代器的 `Limit` 方法限制返回记录数

## 7.7 注意事项

1. **索引必须存在**：搜索操作需要匹配的索引
2. **主键查询最快**：按主键查询是最快的查询方式
3. **范围查询基于索引**：范围查询必须基于索引字段
4. **迭代器必须释放**：使用完迭代器后必须调用 `Release()` 方法
5. **字段类型匹配**：查询条件的字段类型必须与表结构一致

## 7.8 完整示例

以下是一个完整的查询操作示例，展示了如何使用各种查询方法：

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/engine/record"
	"github.com/liaoran123/sfsDb/util"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 1. 按主键查询
	fmt.Println("=== 按主键查询 ===")
	id := 1
	fields := map[string]any{
		"id": id,
	}
	recordBytes, err := table.Read(&fields)
	if err != nil {
		fmt.Println("查询记录失败:", err)
	} else {
		rd, _ := record.Unmarshal(recordBytes)
		fmt.Printf("查询ID为%d的记录成功: %v\n", id, *rd)
	}

	// 2. 范围搜索
	fmt.Println("\n=== 范围搜索 ===")
	start := map[string]any{
		"age": 20,
	}
	limit := map[string]any{
		"age": 30,
	}
	iter, err := table.SearchRange(nil, &start, &limit)
	if err != nil {
		fmt.Println("范围搜索失败:", err)
	} else {
		fmt.Println("年龄在20-30之间的用户:")
		for iter.Next() {
			rd := iter.Record()
			fmt.Printf("%v\n", *rd)
		}
		iter.Release()
	}

	// 3. 条件搜索
	fmt.Println("\n=== 条件搜索 ===")
	searchFields := map[string]any{
		"name": "张",
	}
	iter, err = table.Search(&searchFields)
	if err != nil {
		fmt.Println("搜索失败:", err)
	} else {
		fmt.Println("名字以'张'开头的用户:")
		for iter.Next() {
			rd := iter.Record()
			fmt.Printf("%v\n", *rd)
		}
		iter.Release()
	}

	// 4. 遍历所有数据
	fmt.Println("\n=== 遍历所有数据 ===")
	iter = table.ForData()
	fmt.Println("表中所有用户:")
	count := 0
	for iter.Next() {
		count++
		if count <= 5 { // 只显示前5条
			rd := iter.Record()
			fmt.Printf("%v\n", *rd)
		}
	}
	fmt.Printf("共 %d 条记录\n", count)
	iter.Release()
}
```

## 7.9 总结

查询操作是数据库操作中的重要组成部分，sfsDb提供了多种查询方法以满足不同的使用场景：

- `Read` - 按主键查询单条记录
- `Search` - 条件搜索，支持前缀匹配
- `SearchRange` - 范围搜索，支持区间查询
- `ForData` - 遍历表所有数据

合理使用这些查询方法，可以有效地从数据库中获取所需数据，提高应用程序的性能和效率。
