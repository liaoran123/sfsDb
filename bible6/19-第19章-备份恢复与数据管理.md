## 17.1 完整的可运行示例

让我们通过一个完整的示例来演示 sfsDb 的备份恢复与数据管理功能：

```go
package main

import (
	"fmt"
	"os"

	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/storage"
)

func main() {
	fmt.Println("=== sfsDb 数据库实战 - 第 17 章：备份恢复与数据管理示例 ===")
	fmt.Println()

	dbPath := "./bible_examples_chapter11_db"
	backupPath := "./bible_examples_chapter11_backup"
	cleanup(dbPath)
	cleanup(backupPath)
	defer cleanup(dbPath)
	defer cleanup(backupPath)

	fmt.Println("1. 初始化数据库")
	_, err := storage.GetDBManager().OpenDB(dbPath)
	if err != nil {
		fmt.Printf("数据库打开失败: %v\n", err)
		return
	}
	defer storage.GetDBManager().CloseDB()
	fmt.Println("   ✓ 数据库打开成功")
	fmt.Println()

	fmt.Println("2. 创建表并插入数据")
	table, err := engine.TableNew("important_data")
	if err != nil {
		fmt.Printf("创建表失败: %v\n", err)
		return
	}

	fields := map[string]any{
		"id":      0,
		"content": "",
		"created": 0,
	}
	table.SetFields(fields)

	pk, _ := engine.DefaultPrimaryKeyNew("pk_id")
	pk.AddFields("id")
	table.CreateIndex(pk)

	for i := 1; i <= 10; i++ {
		data := map[string]any{
			"id":      i,
			"content": fmt.Sprintf("重要数据 %d", i),
			"created": int64(i * 1000),
		}
		table.Insert(&data)
	}
	fmt.Println("   ✓ 表创建成功，插入 10 条记录")
	fmt.Println()

	fmt.Println("3. 查看当前数据")
	iter, _ := table.Search(&map[string]any{"id": nil})
	defer iter.Release()
	records := iter.GetRecords(true)
	defer records.Release()
	fmt.Println("   当前数据：")
	for _, r := range records {
		fmt.Printf("   - %v\n", r)
	}
	fmt.Println()

	fmt.Println("4. 备份数据库")
	fmt.Println("   备份操作要点：")
	fmt.Println("   - 可以使用文件系统复制整个数据库目录")
	fmt.Println("   - 建议在业务低峰期进行备份")
	fmt.Println("   - 可以使用快照确保备份数据一致性")
	fmt.Println()

	fmt.Println("5. 模拟数据损坏或丢失")
	fmt.Println("   为了演示恢复，我们先清理一些数据")
	for i := 6; i <= 10; i++ {
		table.Delete(&map[string]any{"id": i})
	}
	fmt.Println("   ✓ 已删除 ID 6-10 的数据")
	fmt.Println()

	fmt.Println("6. 查看删除后的数据")
	iter2, _ := table.Search(&map[string]any{"id": nil})
	defer iter2.Release()
	records2 := iter2.GetRecords(true)
	defer records2.Release()
	fmt.Println("   删除后的数据：")
	for _, r := range records2 {
		fmt.Printf("   - %v\n", r)
	}
	fmt.Println()

	fmt.Println("7. 数据恢复演示")
	fmt.Println("   数据恢复的常见方式：")
	fmt.Println("   - 从备份文件恢复整个数据库")
	fmt.Println("   - 使用导入导出功能恢复部分数据")
	fmt.Println("   - 使用事务回滚（如果适用）")
	fmt.Println()

	fmt.Println("8. 管理工具库功能")
	fmt.Println("   sfsDb 提供 management 包，包含：")
	fmt.Println("   - 系统信息管理：获取表、字段、索引信息")
	fmt.Println("   - 索引管理：分析索引使用情况")
	fmt.Println("   - 性能统计：记录查询性能")
	fmt.Println("   - 配置管理：管理数据库配置")
	fmt.Println("   - 备份恢复：备份和恢复数据库")
	fmt.Println("   - 监控告警：实时监控数据库状态")
	fmt.Println()

	fmt.Println("9. 数据导入导出")
	fmt.Println("   数据导入导出要点：")
	fmt.Println("   - 可以将数据导出为 JSON 格式")
	fmt.Println("   - 可以从 JSON 格式导入数据")
	fmt.Println("   - 适用于数据迁移和备份")
	fmt.Println()
```

## 17.2 备份恢复

### 17.2.1 备份策略

在工业物联网场景中，数据备份非常重要。建议的备份策略：

1. **定期全量备份**：每天或每周进行一次全量备份
2. **增量备份**：在两次全量备份之间进行增量备份
3. **异地备份**：将备份文件存储到不同的位置
4. **备份验证**：定期验证备份文件的完整性

### 17.2.2 备份方法

sfsDb 数据库备份的主要方法：

```go
// 方法1：文件系统级备份（最简单）
// 直接复制整个数据库目录
// 注意：建议在备份前先创建快照确保一致性

// 方法2：使用快照备份
// 1. 创建快照
snapshot, err := db.Snapshot()
if err != nil {
    panic(err)
}
defer snapshot.Release()

// 2. 使用快照迭代器遍历所有数据
iter := snapshot.Iterator(nil, nil)
defer iter.Release()

// 3. 导出所有数据

    key := iter.Key()
```

## 17.3 数据导入导出

### 17.3.1 导出数据为 JSON

```go
// 导出表数据为 JSON
func ExportTableToJSON(table *engine.Table, filename string) error {
    iter, err := table.Search(&map[string]any{"id": nil})
    if err != nil {
        return err
    }
    defer iter.Release()

    records := iter.GetRecords(true)
    defer records.Release()

    jsonData, err := json.MarshalIndent(records, "", "  ")
    if err != nil {
        return err
    }

    return os.WriteFile(filename, jsonData, 0644)
}
```

### 17.3.2 从 JSON 导入数据

```go
// 从 JSON 导入数据到表
func ImportTableFromJSON(table *engine.Table, filename string) error {
    jsonData, err := os.ReadFile(filename)
    if err != nil {
        return err
    }

    var records []map[string]any
    err = json.Unmarshal(jsonData, &records)
    if err != nil {
        return err
    }

    for _, record := range records {
        _, err := table.Insert(&record)
        if err != nil {
            return err
        }
    }

    return nil
}
```

## 17.5 最佳实践

### 17.5.1 备份最佳实践

1. **定期备份**：制定备份计划，定期执行备份
2. **多份备份**：保留多份历史备份
3. **异地存储**：将备份存储到不同位置
4. **备份验证**：定期验证备份的完整性
5. **低峰期备份**：在业务低峰期进行备份

### 17.5.2 数据管理最佳实践

1. **定期清理**：定期清理不需要的历史数据
2. **数据归档**：将历史数据归档到冷存储
3. **索引维护**：定期分析和优化索引
4. **监控统计**：持续监控数据库性能
