## 关于本书

本书将带领您深入了解 sfsDb - 一款专为工业物联网（IIoT）和边缘计算场景设计的纯 Go 语言嵌入式数据库。通过完整的代码示例和实战项目，您将掌握如何在资源受限的边缘设备上构建高性能、可靠的数据存储解决方案。

### 本书特色

- **理论与实践结合**：每个概念都配有可运行的代码示例
- **Go 语言特色**：充分展示 Go 在并发、性能优化方面的优势
- **场景导向**：聚焦工业物联网和边缘计算实际应用
- **生产就绪**：提供可直接用于生产的代码和最佳实践
- **深度解析**：从原理到源码，全面理解 sfsDb 的设计思想

### 目标读者

- Go 语言开发者
- 嵌入式系统开发者
- IoT/边缘计算从业者
- 需要本地数据存储的微服务开发者
- 数据库爱好者和学习者
