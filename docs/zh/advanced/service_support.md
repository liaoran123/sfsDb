# 服务支持

## 概述

sfsDb 采用服务导向的商业模式，为客户提供全方位的技术支持和服务。我们的服务体系旨在确保客户能够顺利使用 sfsDb，解决使用过程中遇到的问题，并获得持续的技术支持。

## 服务等级

### 1. 社区服务（免费）
- **支持渠道**：GitHub Issues（主要）、Gitee Issues（国内替代）
- **响应时间**：社区互助，无官方承诺
- **支持范围**：基础使用问题、文档咨询
- **适合人群**：个人开发者、学生、小型项目

### 2. 专业服务（付费）
- **支持渠道**：邮件、电话、远程协助
- **响应时间**：工作时间内24小时响应
- **支持范围**：技术问题排查、性能优化、配置指导
- **收费方式**：按次或包月收费

### 3. 企业服务（付费）
- **支持渠道**：专属联系人、7×24小时电话
- **响应时间**：紧急问题4小时内响应
- **支持范围**：定制开发、现场部署、培训认证、系统集成
- **收费方式**：项目制收费

## 服务产品化

### 1. 基础支持包
- **价格**：5000元/年
- **包含内容**：
  - 自助服务+远程协助（工作时间）
  - 5次技术咨询
  - 24小时响应
- **适合**：小型项目、初次使用 sfsDb 的客户

### 2. 高级支持包
- **价格**：15000元/年
- **包含内容**：
  - 自助服务+7×24小时远程协助+定期健康检查
  - 无限次技术咨询
  - 4小时响应
  - 2次现场支持（国内主要城市48小时内到达）
- **适合**：中型项目、对服务质量有较高要求的客户

### 3. 企业级支持包
- **价格**：30000元/年起
- **包含内容**：
  - 所有远程服务+现场支持+定制化远程管理解决方案
  - 7×24小时专属工程师
  - 国内主要城市24小时内到达，其他地区48-72小时到达
- **适合**：大型项目、关键业务系统、对服务有极高要求的客户

## 增值服务

### 1. 健康检查
- **内容**：定期（如季度）为客户提供系统健康检查报告，识别潜在风险
- **收费**：可作为独立服务购买，或包含在高级支持包和企业级支持包中

### 2. 灾备方案
- **内容**：为客户设计数据备份和灾难恢复方案
- **收费**：根据方案复杂度和实施难度定价

### 3. 性能优化
- **内容**：针对客户特定场景，提供数据库性能调优服务
- **收费**：根据优化范围和复杂度定价

## 服务流程

### 1. 服务请求提交
- **社区服务**：通过 GitHub Issues 或 Gitee Issues 提交
- **专业服务和企业服务**：通过邮件、电话或专属联系人提交

### 2. 问题分类与分配
- 技术支持团队对问题进行分类和优先级评估
- 根据问题类型和服务等级分配给相应的技术人员

### 3. 问题解决
- **远程优先**：首先通过远程方式解决问题
- **现场支持**：对于复杂问题或远程无法解决的问题，提供现场支持

### 4. 服务跟踪与反馈
- 所有服务请求都有详细的跟踪记录
- 服务完成后进行客户满意度调查
- 定期分析服务数据，持续优化服务流程

## 服务级别协议（SLA）

### 1. 社区服务
- **响应时间**：24-72小时（社区互助）
- **解决时间**：无承诺（取决于问题复杂度）

### 2. 专业服务
- **响应时间**：工作时间内24小时
- **解决时间**：非复杂问题48小时内
- **复杂问题**：7天内提供解决方案

### 3. 企业服务
- **响应时间**：紧急问题4小时内，普通问题8小时内
- **解决时间**：紧急问题24小时内，普通问题72小时内
- **严重问题**：现场支持（根据距离承诺到达时间）

## 服务条款与条件

### 1. 服务有效期
- 服务包自购买之日起计算，有效期为一年
- 到期前30天，我们将发送续费提醒

### 2. 服务范围限制
- 不包括因客户自身硬件故障导致的问题
- 不包括因客户网络环境问题导致的连接问题
- 不包括因客户滥用或误用产品导致的问题
- 不包括需要深度定制开发的功能需求（企业服务除外）

### 3. 责任边界
- 我们负责提供技术支持和服务，但不承担因产品使用不当导致的业务损失
- 客户负责提供必要的技术环境和信息，确保我们能够有效地提供服务

### 4. 保密协议
- 我们将严格保护客户的信息和数据，不会向第三方披露
- 客户同意我们收集必要的服务相关信息，用于服务质量改进

- **技术支持**：享受专业技术支持，快速解决问题

- **试用期退款**：首次购买服务30天内，如不满意可全额退款
- **服务质量退款**：如服务未达到承诺标准，可申请部分退款
- **退款流程**：通过邮件或电话联系我们的客户服务团队，提交退款申请

## 常见问题（FAQ）

### 1. 服务内容
- **问**：各服务等级具体包含哪些内容？
- **答**：请参考"服务等级"和"服务产品化"部分的详细说明。

### 2. 支持响应
- **问**：如何确保支持响应时间？
- **答**：我们有专门的技术支持团队和服务管理系统，确保按照承诺的时间响应客户请求。

### 3. 现场支持
- **问**：现场支持的具体流程是什么？
- **答**：客户提出现场支持需求后，我们会评估问题复杂度，安排合适的技术工程师，并根据距离承诺到达时间。

### 4. 服务升级
- **问**：如何从低等级服务升级到高等级服务？
- **答**：可以随时联系我们的客户服务团队，申请服务等级升级，差价部分按剩余服务期限计算。

### 5. 服务终止
- **问**：服务终止的条件和流程是什么？
- **答**：服务期满未续费或客户主动终止服务，服务将自动终止。终止前，我们会协助客户完成必要的数据迁移和备份工作。

## 与定价策略的对应关系

我们的服务支持体系与国内市场优化策略中的定价策略完全对应：

- **社区服务**：对应定价策略中的社区版，免费提供基础支持
- **专业服务**：对应定价策略中的专业版，提供按次或包月收费的技术支持
- **企业服务**：对应定价策略中的企业版，提供项目制收费的全方位支持

服务包价格与定价策略中的服务等级保持一致，确保客户能够获得与其付费水平相匹配的服务体验。
