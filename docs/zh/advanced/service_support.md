# 服务支持

## 概述

sfsDb 采用服务导向的商业模式，为客户提供全方位的技术支持和服务。我们的服务体系旨在确保客户能够顺利使用 sfsDb，解决使用过程中遇到的问题，并获得持续的技术支持。

## 服务等级

### 1. 社区服务（免费）
- **支持渠道**：GitHub Issues
- **响应时间**：社区互助，无官方承诺
- **支持范围**：基础使用问题、文档咨询
- **适合人群**：个人开发者、学生、小型项目

### 2. 专业服务（付费）
- **支持渠道**：邮件、电话、远程协助
- **响应时间**：工作时间内24小时响应
- **支持范围**：技术问题排查、性能优化、配置指导
- **收费方式**：按次或包月收费

### 3. 企业服务（付费）
- **支持渠道**：专属联系人、7×24小时电话
- **响应时间**：紧急问题4小时内响应
- **支持范围**：定制开发、现场部署、培训认证、系统集成
- **收费方式**：项目制收费

## 服务产品化

### 1. 基础运维包
- **价格**：5000元/年
- **适用对象**：个人开发者、初创项目、非关键业务测试环境
- **包含内容**：
  - 远程自助诊断工具+工作日远程协助
  - 5次轻量级技术咨询（单次≤30分钟）
  - 24小时故障响应（邮件/工单）
  - 基础文档与知识库权限
- **节点限制**：支持1-5个边缘节点
- **价值点**：低成本入门，解决基础适配与配置问题
- **适合**：小型项目、初次使用 sfsDb 的客户

### 2. 高级保障包
- **价格**：15000元/年
- **适用对象**：中型企业、生产环境、高可用性要求场景
- **包含内容**：
  - 7×24小时远程监控与协助
  - 无限次技术咨询（含复杂问题排查）
  - 4小时紧急响应（P1级故障）
  - 每月1次远程健康检查（含数据库碎片、锁状态分析）
  - 2次现场支持（差旅费实报实销，单次≤2人天）
- **节点限制**：支持1-50个边缘节点
- **价值点**：生产环境兜底，通过健康检查预防边缘端数据损坏风险
- **适合**：中型项目、对服务质量有较高要求的客户

### 3. 企业尊享包
- **价格**：30000元/年起
- **适用对象**：大型企业、关键业务系统、多节点分布式边缘集群
- **包含内容**：
  - 7×24小时专属工程师驻场（远程）
  - 不限次现场支持（差旅费实报实销）
  - 定制化远程管理方案（含数据同步策略、断网续传逻辑设计）
  - SLA协议（99.9%可用性承诺）
  - 优先获取新版本测试权限
- **节点限制**：支持50个以上边缘节点
- **价值点**：专家级贴身服务，解决复杂边缘-云端数据协同难题
- **适合**：大型项目、关键业务系统、对服务有极高要求的客户

## 增值服务

### 1. 健康检查
- **内容**：定期（如季度）为客户提供系统健康检查报告，识别潜在风险
- **收费**：5000元/次，提供系统健康检查报告和优化建议

### 2. 灾备方案
- **内容**：为客户设计数据备份和灾难恢复方案
- **收费**：10000元起，根据方案复杂度和实施难度定价

### 3. 性能优化
- **内容**：针对客户特定场景，提供数据库性能调优服务
- **收费**：8000元/次，针对特定场景的性能调优

### 4. 定制开发
- **内容**：根据客户特定需求，提供定制化开发服务
- **收费**：20000元/人月起，高难度任务（如内核修改、跨平台移植）25000元/人月以上

## 专项服务与附加项

- **现场支持差旅费**：实报实销，标准如下：交通费（高铁二等座/飞机经济舱）、住宿费（一线城市≤500元/天，二线城市≤400元/天）、餐补（100元/天）
- **紧急故障加急费**：非工作时间（夜间22:00-次日8:00）紧急响应，加收50%服务费
- **硬件适配费**：针对非标准边缘设备（如特种工业网关）的驱动开发，按1500元/人天单独报价

## 服务流程

### 1. 服务请求提交
- **社区服务**：通过 GitHub Issues 提交
- **专业服务和企业服务**：通过邮件、电话或专属联系人提交

### 2. 问题分类与分配
- 技术支持团队对问题进行分类和优先级评估
- 根据问题类型和服务等级分配给相应的技术人员

### 3. 问题解决
- **远程优先**：首先通过远程方式解决问题
- **现场支持**：对于复杂问题或远程无法解决的问题，提供现场支持

### 4. 服务跟踪与反馈
- 所有服务请求都有详细的跟踪记录
- 服务完成后进行客户满意度调查
- 定期分析服务数据，持续优化服务流程

## 服务级别协议（SLA）

### 1. 社区服务
- **响应时间**：24-72小时（社区互助）
- **解决时间**：无承诺（取决于问题复杂度）

### 2. 专业服务
- **响应时间**：工作时间内24小时
- **解决时间**：非复杂问题48小时内
- **复杂问题**：7天内提供解决方案

### 3. 企业服务
- **响应时间**：紧急问题4小时内，普通问题8小时内
- **解决时间**：紧急问题24小时内，普通问题72小时内
- **严重问题**：现场支持（根据距离承诺到达时间）

## 服务条款与条件

### 1. 服务有效期
- 服务包自购买之日起计算，有效期为一年
- 到期前30天，我们将发送续费提醒

### 2. 服务范围限制
- 不包括因客户自身硬件故障导致的问题
- 不包括因客户网络环境问题导致的连接问题
- 不包括因客户滥用或误用产品导致的问题
- 不包括需要深度定制开发的功能需求（企业服务除外）

### 3. 责任边界
- 我们负责提供技术支持和服务，但不承担因产品使用不当导致的业务损失
- 客户负责提供必要的技术环境和信息，确保我们能够有效地提供服务

### 4. 保密协议
- 我们将严格保护客户的信息和数据，不会向第三方披露
- 客户同意我们收集必要的服务相关信息，用于服务质量改进

## 常见问题（FAQ）

### 1. 服务内容
- **问**：各服务等级具体包含哪些内容？
- **答**：请参考"服务等级"和"服务产品化"部分的详细说明。

### 2. 支持响应
- **问**：如何确保支持响应时间？
- **答**：我们有专门的技术支持团队和服务管理系统，确保按照承诺的时间响应客户请求。

### 3. 现场支持
- **问**：现场支持的具体流程是什么？
- **答**：客户提出现场支持需求后，我们会评估问题复杂度，安排合适的技术工程师，并根据距离承诺到达时间。

### 4. 服务升级
- **问**：如何从低等级服务升级到高等级服务？
- **答**：可以随时联系我们的客户服务团队，申请服务等级升级，差价部分按剩余服务期限计算。

### 5. 服务终止
- **问**：服务终止的条件和流程是什么？
- **答**：服务期满未续费或客户主动终止服务，服务将自动终止。终止前，我们会协助客户完成必要的数据迁移和备份工作。

## 与定价策略的对应关系

我们的服务支持体系与国内市场优化策略中的定价策略完全对应：

- **社区服务**：对应定价策略中的免费社区服务
- **基础运维包**：对应定价策略中的基础服务包，提供入门级支持
- **高级保障包**：对应定价策略中的高级服务包，提供生产环境级支持
- **企业尊享包**：对应定价策略中的企业服务包，提供专家级支持

服务包价格与定价策略中的服务等级保持一致，确保客户能够获得与其付费水平相匹配的服务体验。
