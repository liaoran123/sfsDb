## 关于本书

《sfsDb 数据库实战》是一本面向工业物联网（IIoT）和边缘计算场景的 Go 语言嵌入式数据库实战指南。本书遵循《Go 程序设计语言》（The Go Programming Language）的写作风格，通过真实的代码示例和测试用例，循序渐进地讲解 sfsDb 的核心原理和实战应用。

### 本书特色

- **代码驱动**：所有示例均来自 sfsDb 项目的实际代码和测试代码
- **实战导向**：每个概念都配有可运行的完整代码示例
- **深度解析**：从 API 到源码，全面理解 sfsDb 的设计思想
- **生产就绪**：提供可直接用于生产的最佳实践

### 读者对象

- Go 语言开发者
- 工业物联网开发者
- 边缘计算架构师
- 数据库工程师
- 对嵌入式数据库感兴趣的技术人员
