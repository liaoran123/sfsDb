## 25.1 核心 API 接口

### 25.1.1 Engine 包

#### TableNew

创建一个新表。

**签名：**
```go
func TableNew(name string) (*Table, error)
```

**参数：**
- `name`：表名

**返回值：**
- `*Table`：表对象
- `error`：错误信息

**示例：**
```go
table, err := engine.TableNew("users")
if err != nil {
    fmt.Printf("创建表失败: %v\n", err)
    return
}
```

#### Table.SetFields

设置表的字段结构。

**签名：**
```go
func (t *Table) SetFields(fields map[string]any) error
```

**参数：**
- `fields`：字段映射，键为字段名，值为字段类型的默认值

**返回值：**
- `error`：错误信息

**示例：**
```go
fields := map[string]any{
    "id":     0,
    "name":   "",
    "age":    0,
    "email":  "",
    "active": false,
}
table.SetFields(fields)
```

#### Table.CreateIndex

创建索引。

**签名：**
```go
func (t *Table) CreateIndex(index Index) error
```

**参数：**
- `index`：索引对象

**返回值：**
- `error`：错误信息

**示例：**
```go
pk, _ := engine.DefaultPrimaryKeyNew("pk_id")
pk.AddFields("id")
table.CreateIndex(pk)
```

#### Table.Insert

插入数据。

**签名：**
```go
func (t *Table) Insert(data *map[string]any) (string, error)
```

**参数：**
- `data`：数据映射

**返回值：**
- `string`：插入的数据ID
- `error`：错误信息

**示例：**
```go
user := map[string]any{
    "id":     1,
    "name":   "Alice",
    "age":    25,
    "email":  "alice@example.com",
    "active": true,
}
_, err := table.Insert(&user)
```

#### Table.Search

搜索数据。

**签名：**
```go
func (t *Table) Search(query *map[string]any) (TableIter, error)
```

**参数：**
- `query`：搜索条件

**返回值：**
- `TableIter`：表迭代器
- `error`：错误信息

**示例：**
```go
query := map[string]any{"age": 25}
iter, err := table.Search(&query)
if err != nil {
    fmt.Printf("搜索失败: %v\n", err)
    return
}
defer iter.Release()
```

### 25.1.2 Record 包

#### GetRecord

从对象池获取一个 Record 对象。

**签名：**
```go
func GetRecord() Record
```

**返回值：**
- `Record`：记录对象

**示例：**
```go
r := record.GetRecord()
defer r.Release()
r["id"] = 1
r["name"] = "Alice"
```

#### GetRecords

从对象池获取一个 Records 对象。

**签名：**
```go
func GetRecords() Records
```

**返回值：**
- `Records`：记录集合

**示例：**
```go
records := record.GetRecords()
defer records.Release()
```

#### Record.Select

选择记录中的指定字段。

**签名：**
```go
func (r Record) Select(keys ...string) Record
```

**参数：**
- `keys`：要选择的字段名

**返回值：**
- `Record`：新的记录对象

**示例：**
```go
selected := r.Select("id", "name")
```

### 25.1.3 Storage 包

#### GetDBManager

获取数据库管理器实例。

**签名：**
```go
func GetDBManager() *DBManager
```

**返回值：**
- `*DBManager`：数据库管理器

**示例：**
```go
dbManager := storage.GetDBManager()
```

#### DBManager.OpenDB

打开数据库。

**签名：**
```go
func (dm *DBManager) OpenDB(path string, encryptConfig ...*EncryptionConfig) (Store, error)
```

**参数：**
- `path`：数据库路径
- `encryptConfig`：加密配置（可选）

**返回值：**
- `Store`：存储接口
- `error`：错误信息

**示例：**
```go
db, err := storage.GetDBManager().OpenDB("./mydb")
if err != nil {
    fmt.Printf("打开数据库失败: %v\n", err)
    return
}
defer storage.GetDBManager().CloseDB()
```

## 25.2 配置选项

### 25.2.1 存储配置

#### GetScenarioOptions

根据场景获取存储配置。

**签名：**
```go
func GetScenarioOptions(scenario string) *opt.Options
```

**参数：**
- `scenario`：场景名称（"embedded", "iot", "edge", "game"）

**返回值：**
- `*opt.Options`：LevelDB 配置选项

**示例：**
```go
opts := storage.GetScenarioOptions("iot")
db, err := storage.GetDBManager().NewLevelDBStore("./mydb", opts)
```

### 25.2.2 索引配置

#### SetIndexCacheSizeLimit

设置索引缓存大小限制。

**签名：**
```go
func SetIndexCacheSizeLimit(limit int)
```

**参数：**
- `limit`：缓存大小限制（单位：条）

**示例：**
```go
engine.SetIndexCacheSizeLimit(10000)
```

## 25.3 错误处理

### 25.3.1 存储错误

```go
var (
    ErrNotFound     = NewError("key not found")
    ErrInvalidKey   = NewError("invalid key")
    ErrInvalidValue = NewError("invalid value")
    ErrStoreClosed  = NewError("store is closed")
)
```

**使用示例：**
```go
value, err := db.Get([]byte("key"))
if err == storage.ErrNotFound {
    fmt.Println("key不存在")
} else if err != nil {
    fmt.Printf("读取错误: %v\n", err)
}
```

### 25.3.2 表错误

**常见错误：**
- 表已存在
- 字段类型不匹配
- 主键重复
- 索引创建失败

**处理示例：**
```go
table, err := engine.TableNew("users")
if err != nil {
    if strings.Contains(err.Error(), "already exists") {
        fmt.Println("表已存在")
    } else {
        fmt.Printf("创建表失败: %v\n", err)
    }
    return
}
```

## 25.4 性能基准测试

### 25.4.1 写入性能测试

**测试方法：**
```go
func BenchmarkTable_Insert(b *testing.B) {
    // 初始化数据库
    dbPath := "./benchmark_db"
    os.RemoveAll(dbPath)
    defer os.RemoveAll(dbPath)
    
    _, err := storage.GetDBManager().OpenDB(dbPath)
    if err != nil {
        b.Fatalf("打开数据库失败: %v", err)
    }
    defer storage.GetDBManager().CloseDB()
    
    // 创建表
    table, err := engine.TableNew("benchmark")
    if err != nil {
        b.Fatalf("创建表失败: %v", err)
    }
    
    fields := map[string]any{
        "id":   0,
        "name": "",
        "value": 0.0,
    }
    table.SetFields(fields)
    
    pk, _ := engine.DefaultPrimaryKeyNew("pk_id")
    pk.AddFields("id")
    table.CreateIndex(pk)
    
    // 基准测试
    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        data := map[string]any{
            "id":   i,
            "name": fmt.Sprintf("item%d", i),
            "value": float64(i),
        }
        _, err := table.Insert(&data)
        if err != nil {
            b.Fatalf("插入失败: %v", err)
        }
    }
}
```

## 25.5 最佳实践

1. **连接管理**：使用 `DBManager` 管理数据库连接，确保全局唯一实例
2. **资源释放**：使用 `defer` 释放迭代器、记录和数据库连接
3. **批量操作**：对于大量数据操作，使用批量写入提高性能
4. **索引使用**：为频繁查询的字段创建索引
5. **错误处理**：正确处理各种错误类型
6. **内存管理**：使用对象池减少内存分配
7. **配置优化**：根据应用场景选择合适的存储配置
