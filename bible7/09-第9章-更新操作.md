# 第6章 更新操作

更新操作是数据库CRUD操作中的重要组成部分，sfsDb提供了多种更新记录的方法，包括更新单条记录和通过迭代器更新符合条件的记录。本章将详细介绍这些更新操作的实现和使用方法。

## 6.1 更新单条记录

### 6.1.1 函数签名

```go
func (t *Table) Update(fields *map[string]any, batchs ...storage.Batch) error
```

### 6.1.2 参数说明

- `fields *map[string]any` - 包含主键值和要更新的字段值，可能是组合主键
- `batchs ...storage.Batch` - 批量操作对象，支持乐观锁

### 6.1.3 实现原理

更新单条记录的实现流程如下：

1. 创建UpdateImpl实例
2. 检查参数
3. 准备批量操作
4. 读取记录
5. 准备更新字段
6. 获取字段字节
7. 删除旧记录
8. 添加新记录
9. 提交事务

### 6.1.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 准备更新数据（包含主键和要更新的字段）
	id := 1
	fields := map[string]any{
		"id":   id,      // 主键
		"name": "张三",  // 要更新的字段
		"age":  25,      // 要更新的字段
	}

	// 执行更新操作
	err = table.Update(&fields)
	if err != nil {
		fmt.Println("更新记录失败:", err)
		return
	}

	fmt.Printf("更新ID为%d的记录成功\n", id)
}
```

## 6.2 通过迭代器更新记录

### 6.2.1 函数签名

```go
func (t *TableIter) Update(fields *map[string]any, limit ...int) error
```

### 6.2.2 参数说明

- `fields *map[string]any` - 要更新的字段值
- `limit ...int` - 可选参数，限制更新记录的数量

### 6.2.3 实现原理

通过迭代器更新记录的实现流程如下：

1. 获取批量操作对象
2. 遍历迭代器中的记录
3. 检查记录是否存在主键字段
4. 从记录中提取主键值并合并更新字段
5. 执行更新操作
6. 统计更新成功的记录数
7. 执行批量操作

### 6.2.4 使用示例

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/engine/record"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 创建查询条件
	query := record.NewQuery()
	query.GreaterThan("age", 30) // 更新年龄大于30的记录

	// 准备更新数据
	updateFields := map[string]any{
		"status": "inactive", // 将状态更新为inactive
	}

	// 获取迭代器
	iter := table.Where(query)
	defer iter.Release()

	// 执行更新操作，限制更新10条记录
	err = iter.Update(&updateFields, 10)
	if err != nil {
		fmt.Println("更新记录失败:", err)
		return
	}

	fmt.Println("更新符合条件的记录成功")
}
```

## 6.3 内部实现细节

### 6.3.1 UpdateImpl结构

`Update` 方法内部使用 `UpdateImpl` 结构来处理更新操作，它负责：

- 检查参数
- 准备批量操作
- 读取记录
- 准备更新字段
- 获取字段字节
- 删除旧记录
- 添加新记录
- 提交事务

### 6.3.2 更新操作的实现机制

更新操作的实现机制是：

1. 先读取旧记录
2. 准备更新后的字段
3. 删除旧记录
4. 添加新记录

这种实现方式确保了数据的一致性和完整性。

### 6.3.3 批量操作优化

更新操作使用批量操作来提高性能，特别是通过迭代器更新多条记录时，会：

- 批量处理多条记录
- 减少磁盘I/O操作
- 提高更新效率

### 6.3.4 错误处理

更新操作的错误处理包括：

- 检查参数是否正确
- 处理记录不存在的情况
- 确保批量操作的正确执行
- 检查是否存在主键字段

## 6.4 性能优化建议

1. **使用批量操作**：当更新多条记录时，使用迭代器的 `Update` 方法可以批量处理，提高性能
2. **减少更新字段**：只更新必要的字段，减少数据传输和处理开销
3. **使用索引**：更新操作会涉及索引的更新，确保索引设计合理
4. **避免更新主键**：sfsDb不支持修改主键字段，设计表结构时应考虑主键的稳定性

## 6.5 注意事项

1. **主键必须提供**：更新操作必须提供主键值
2. **不支持修改主键**：sfsDb不支持修改主键字段
3. **记录不存在的处理**：当更新不存在的记录时，会返回"记录不存在"的错误
4. **事务处理**：更新操作会在事务中执行，确保数据一致性
5. **索引更新**：更新记录时会自动更新相关索引

## 6.6 完整示例

以下是一个完整的更新操作示例，展示了如何使用各种更新方法：

```go
package main

import (
	"fmt"
	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/engine/record"
)

func main() {
	// 打开数据库
	db, err := engine.Open("test_db")
	if err != nil {
		fmt.Println("打开数据库失败:", err)
		return
	}
	defer db.Close()

	// 获取表
	table, err := db.GetTable("users")
	if err != nil {
		fmt.Println("获取表失败:", err)
		return
	}

	// 1. 更新单条记录
	fmt.Println("=== 更新单条记录 ===")
	id := 1
	fields := map[string]any{
		"id":   id,
		"name": "张三",
		"age":  25,
	}
	err = table.Update(&fields)
	if err != nil {
		fmt.Println("更新记录失败:", err)
	} else {
		fmt.Printf("更新ID为%d的记录成功\n", id)
	}

	// 2. 通过迭代器更新记录
	fmt.Println("\n=== 通过迭代器更新记录 ===")
	query := record.NewQuery()
	query.LessThan("age", 20) // 更新年龄小于20的记录
	updateFields := map[string]any{
		"status": "active",
	}
	iter := table.Where(query)
	err = iter.Update(&updateFields, 5) // 限制更新5条
	if err != nil {
		fmt.Println("更新记录失败:", err)
	} else {
		fmt.Println("更新符合条件的记录成功")
	}
	iter.Release()
}
```

## 6.7 总结

更新操作是数据库操作中的重要组成部分，sfsDb提供了多种更新方法以满足不同的使用场景：

- `Update` - 更新单条记录，需要提供主键
- `TableIter.Update` - 通过迭代器更新符合条件的记录，支持批量操作和数量限制

合理使用这些更新方法，可以有效地管理数据库中的数据，保持数据的准确性和一致性。
