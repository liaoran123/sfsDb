## 19.2 Web 包概述

sfsDb 提供 web 包，用于快速集成 Web API 服务。web 包基于 Gin 框架，提供了完整的 RESTful API 接口。

### 19.2.1 Server 结构体

`web` 包的核心是 `Server` 结构体，它封装了 Gin 引擎和路由配置：

**代码来源**: `web/server.go:1-50`

```go
type Server struct {
	engine *gin.Engine
	config *ServerConfig
}

type ServerConfig struct {
	Addr         string
	ReadTimeout  time.Duration
	WriteTimeout time.Duration
	IdleTimeout  time.Duration

```

### 19.2.2 创建服务器

使用 `NewServer` 函数创建 Web 服务器：

**代码来源**: `web/server.go:52-80`

```go
func NewServer(config *ServerConfig) (*Server, error) {
	if config == nil {
		config = &ServerConfig{
			Addr:         ":8080",
			ReadTimeout:  30 * time.Second,
			WriteTimeout: 30 * time.Second,
			IdleTimeout:  60 * time.Second,
		}
	}

	engine := gin.Default()

	server := &Server{
		engine: engine,
		config: config,
	}

	server.registerRoutes()
	return server, nil
}
```

### 19.2.3 TLS 支持

web 包也支持 TLS 加密传输：

**代码来源**: `web/server.go:82-110`

```go
func NewServerWithTLS(config *ServerConfig, certFile, keyFile string) (*Server, error) {
	server, err := NewServer(config)
	if err != nil {
		return nil, err
	}

	server.tlsCert = certFile
	server.tlsKey = keyFile
	return server, nil
}
```

### 19.2.4 启动服务器

使用 `Start` 方法启动服务器：

**代码来源**: `web/server.go:112-150`

```go
func (s *Server) Start() error {
	httpServer := &http.Server{
		Addr:         s.config.Addr,
		Handler:      s.engine,
		ReadTimeout:  s.config.ReadTimeout,
		WriteTimeout: s.config.WriteTimeout,
		IdleTimeout:  s.config.IdleTimeout,
	}

	if s.tlsCert != "" && s.tlsKey != "" {
		return httpServer.ListenAndServeTLS(s.tlsCert, s.tlsKey)
	}

	return httpServer.ListenAndServe()
}
```

## 19.3 API 路由注册

web 包自动注册了所有 API 路由：

**代码来源**: `web/server.go:152-200`

```go
func (s *Server) registerRoutes() {
	api := s.engine.Group("/api")
	{
		// 状态和系统信息
		api.GET("/status", handleStatus)
		api.GET("/system", handleSystem)

		// 配置管理
		api.GET("/config", handleConfig)
		api.POST("/config", handleUpdateConfig)

		// 备份恢复
		api.POST("/backup", handleBackup)
		api.POST("/restore", handleRestore)

		// 监控
		api.GET("/monitor", handleMonitor)

		// 认证
		api.POST("/api-key", handleGenerateAPIKey)
		api.POST("/revoke-key", handleRevokeAPIKey)

		// 诊断
		api.GET("/diagnostic", handleDiagnostic)

		// 导入导出
		api.POST("/export", handleExportTable)
		api.POST("/import", handleImportTable)
	}

	// 静态文件服务
	s.engine.Static("/static", "./static")
	s.engine.LoadHTMLGlob("./templates/*")
	s.engine.GET("/", func(c *gin.Context) {
		c.HTML(http.StatusOK, "index.html", nil)
	})
}
```

## 19.5 完整使用示例

**代码来源**: `web_main.go:1-100`

```go
package main

import (
	"log"
	"os"
	"os/signal"
	"syscall"
	"time"

	"github.com/liaoran123/sfsDb/web"
)

func main() {
	config := &web.ServerConfig{
		Addr:         ":8080",
		ReadTimeout:  30 * time.Second,
		WriteTimeout: 30 * time.Second,
		IdleTimeout:  60 * time.Second,
	}

	server, err := web.NewServer(config)
	if err != nil {
		log.Fatalf("Failed to create server: %v", err)
	}

	go func() {
		log.Printf("Server starting on %s", config.Addr)
		if err := server.Start(); err != nil {
			log.Fatalf("Server error: %v", err)
		}
	}()

	quit := make(chan os.Signal, 1)
	signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
	<-quit

	log.Println("Server shutting down...")
}
```

## 19.6 安全最佳实践
