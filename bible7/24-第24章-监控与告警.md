## 18.1 完整的可运行示例

让我们通过一个完整的示例来演示 sfsDb 的监控与告警功能：

```go
package main

import (
	"fmt"
	"os"
	"time"

	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/storage"
)

func main() {
	fmt.Println("=== sfsDb 数据库实战 - 第 18 章：监控与告警示例 ===")
	fmt.Println()

	dbPath := "./bible_examples_chapter12_db"
	cleanup(dbPath)
	defer cleanup(dbPath)

	fmt.Println("1. 初始化数据库")
	_, err := storage.GetDBManager().OpenDB(dbPath)
	if err != nil {
		fmt.Printf("数据库打开失败: %v\n", err)
		return
	}
	defer storage.GetDBManager().CloseDB()
	fmt.Println("   ✓ 数据库打开成功")
	fmt.Println()

	fmt.Println("2. 创建表并测试索引")
	table, err := engine.TableNew("monitor_test")
	if err != nil {
		fmt.Printf("创建表失败: %v\n", err)
		return
	}

	fields := map[string]any{
		"id":    0,
		"name":  "",
		"value": 0,
	}
	table.SetFields(fields)

	pk, _ := engine.DefaultPrimaryKeyNew("pk_id")
	pk.AddFields("id")
	table.CreateIndex(pk)

	nameIndex, _ := engine.DefaultNormalIndexNew("idx_name")
	nameIndex.AddFields("name")
	table.CreateIndex(nameIndex)
	fmt.Println("   ✓ 表创建成功，包含 2 个索引")
	fmt.Println()

	fmt.Println("3. 执行数据库操作（产生监控数据）")
	for i := 1; i <= 100; i++ {
		data := map[string]any{
			"id":    i,
			"name":  fmt.Sprintf("Item %d", i),
			"value": i * 10,
		}
		table.Insert(&data)
	}
	fmt.Println("   ✓ 成功插入 100 条记录")
	fmt.Println()

	fmt.Println("4. 执行查询操作")
	for i := 1; i <= 50; i++ {
		search := map[string]any{"id": i}
		iter, _ := table.Search(&search)
		iter.Release()
	}
	fmt.Println("   ✓ 成功执行 50 次查询")
	fmt.Println()

	fmt.Println("5. 查看索引缓存统计")
	stats := engine.GetIndexMatchCacheStats()
	fmt.Println("   索引缓存统计：")
	fmt.Printf("   - 缓存大小: %d\n", stats.Size)
	fmt.Printf("   - 访问次数: %d\n", stats.Accesses)
	fmt.Printf("   - 命中次数: %d\n", stats.Hits)
	fmt.Printf("   - 命中率: %.2f%%\n", stats.HitRate*100)
	fmt.Println()

	fmt.Println("6. 监控系统介绍")
	fmt.Println("   sfsDb 提供 monitor 包，包含：")
	fmt.Println("   - 键值变化监控")
	fmt.Println("   - 索引使用统计")
	fmt.Println("   - 性能统计记录")
	fmt.Println("   - 阈值告警设置")
	fmt.Println()

	fmt.Println("7. 告警阈值设置示例")
	fmt.Println("   常见的告警阈值：")
	fmt.Println("   - 内存使用超过限制")
	fmt.Println("   - GC 次数异常增多")
	fmt.Println("   - 查询延迟超过阈值")
	fmt.Println("   - 索引命中率过低")
	fmt.Println()

	fmt.Println("8. 监控最佳实践")
	fmt.Println("   - 定期收集性能指标")
	fmt.Println("   - 设置合理的告警阈值")
	fmt.Println("   - 及时处理告警")
	fmt.Println("   - 记录监控历史")
	fmt.Println("   - 定期分析监控数据")
	fmt.Println()

	fmt.Println("=== 监控与告警示例完成！===")
}

func cleanup(path string) {
	os.RemoveAll(path)
}
```

## 18.4 告警系统

### 18.4.1 阈值告警

在工业物联网场景中，可以设置以下告警阈值：

```go
// 告警阈值配置示例
type Thresholds struct {
    MemoryUsage int64  // 内存使用阈值（MB）
    GCCount     int    // GC 次数阈值
    QueryLatency time.Duration // 查询延迟阈值
    IndexHitRate float64 // 索引命中率阈值
}
```

### 18.4.2 告警处理

当监控指标超过阈值时，应该：

1. **记录告警**：记录告警时间、指标、阈值
2. **通知相关人员**：通过邮件、短信等方式通知
3. **自动处理**：如果可能，自动采取措施（如清理缓存）
4. **分析原因**：分析告警产生的原因
5. **优化改进**：根据分析结果进行优化
