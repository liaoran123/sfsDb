## 18.2 对象池概述

对象池是 sfsDb 性能优化的核心机制之一。它通过重用频繁创建和销毁的对象，显著减少内存分配和垃圾回收的开销，特别适合高并发和大数据量场景。

### 对象池的优势

1. **减少内存分配**：避免频繁的内存分配和释放
2. **降低 GC 压力**：减少垃圾回收器的工作负担
3. **提高响应速度**：对象重用减少了创建时间
4. **稳定内存使用**：避免内存使用的剧烈波动

---

## 18.3 核心对象池

### 18.3.1 表迭代器池

表迭代器池 (`GlobalTableIterPool`) 用于管理 `TableIter` 对象的重用。

**示例代码**（来自项目源码）：

```go
// 获取迭代器
iter, _ := table.Search(&searchFields)
defer iter.Release() // 使用完毕后归还到池

// 使用迭代器
records := iter.GetRecords(true)
defer records.Release()
```

**最佳实践**：
- 使用 `defer` 确保迭代器在任何情况下都能归还
- 避免在循环中重复获取和归还迭代器
- 及时释放不再使用的迭代器

---

### 18.3.2 记录池

记录池用于管理查询结果记录的重用。

**示例代码**（来自项目源码）：

```go
// 获取记录
records := iter.GetRecords(true)
defer records.Release() // 使用完毕后归还到池

// 使用记录
for _, r := range records {
    fmt.Println(r)
}
```

**记录池特点**：
- 自动管理记录对象的生命周期
- 支持批量记录的重用
- 减少内存碎片

---

### 18.3.3 字节数组池

字节数组池用于管理字节数组的重用。

**示例代码**（来自项目源码）：

```go
// 获取字节数组
joinValues := index.JoinFullValues(fieldsBytes, t.id)
defer joinValues.Release() // 使用完毕后归还到池
```

**字节数组池应用场景**：
- 索引键值拼接
- 数据序列化
- 临时缓冲区

## 18.4 对象池使用最佳实践

### 18.4.1 正确使用 defer 归还对象

**推荐做法**：

```go
// 获取迭代器
iter, _ := table.Search(&searchFields)
defer iter.Release() // 确保使用完毕后归还

// 获取记录
records := iter.GetRecords(true)
defer records.Release() // 确保使用完毕后归还

// 使用迭代器和记录...
```

**避免做法**：
- 忘记归还对象到池
- 在错误路径中没有归还对象
- 重复释放同一个对象

---

### 18.4.2 批量操作中的对象池使用

在批量操作中，正确使用对象池尤为重要：

```go
// 批量操作示例
for i := 0; i < 1000; i++ {
    // 获取迭代器
    iter, _ := table.Search(&searchFields)
    defer iter.Release()
    
    // 获取记录
    records := iter.GetRecords(true)
    defer records.Release()
    
    // 使用记录...
}
```

**注意事项**：
- 在循环外部使用 defer 可能导致资源堆积
- 对于大量循环，考虑手动管理对象生命周期
- 监控内存使用，避免对象池过大

## 18.6 对象池实现原理

### 18.6.1 基本实现

对象池的基本实现原理是维护一个对象集合：

```go
// 简化的对象池实现
type ObjectPool struct {
    pool chan interface{}
}

func NewObjectPool(size int) *ObjectPool {
    return &ObjectPool{
        pool: make(chan interface{}, size),
    }
}

func (p *ObjectPool) Get() interface{} {
    select {
    case obj := <-p.pool:
        return obj // 从池中获取
    default:
        return createNewObject() // 池中无对象，创建新对象
    }
}

func (p *ObjectPool) Put(obj interface{}) {
    select {
    case p.pool <- obj: // 归还到池
    default: // 池已满，丢弃
    }
}
```

---

### 18.6.2 线程安全

sfsDb 的对象池实现是线程安全的：

- 使用通道 (`chan`) 实现线程安全的对象传递
- 采用非阻塞操作，避免 goroutine 阻塞
- 池满时自动丢弃多余对象，防止内存无限增长
