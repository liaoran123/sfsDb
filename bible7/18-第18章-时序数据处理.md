# 第 14 章：时序数据处理

## 14.1 完整的可运行示例

让我们通过一个完整的示例来演示 sfsDb 的时序数据处理功能：

```go
package main

import (
	"fmt"
	"time"

	"github.com/liaoran123/sfsDb/record"
	"github.com/liaoran123/sfsDb/time"
)

func main() {
	fmt.Println("=== sfsDb 数据库实战 - 第 14 章：时序数据处理示例 ===")
	fmt.Println()

	now := time.Date(2024, 12, 25, 14, 30, 45, 123456789, time.UTC)
	fmt.Printf("当前时间: %s\n\n", now)

	fmt.Println("1. 时间粒度格式化")
	granularities := []struct {
		name string
		g    time.TimeGranularity
	}{
		{"秒", time.TimeGranularitySecond},
		{"分钟", time.TimeGranularityMinute},
		{"小时", time.TimeGranularityHour},
		{"天", time.TimeGranularityDay},
		{"周", time.TimeGranularityWeek},
		{"月", time.TimeGranularityMonth},
		{"季度", time.TimeGranularityQuarter},
		{"年", time.TimeGranularityYear},
	}

	for _, gg := range granularities {
		formatted := time.FormatTimeByGranularity(now, gg.g)
		fmt.Printf("   %-4s: %s\n", gg.name, formatted)
	}
	fmt.Println()

	fmt.Println("2. 创建滚动窗口")
	startTime := time.Date(2024, 12, 25, 10, 0, 0, 0, time.UTC)
	endTime := time.Date(2024, 12, 25, 14, 0, 0, 0, time.UTC)
	tumblingWindow := time.NewTumblingWindow(startTime, endTime, time.Hour)
	fmt.Printf("   时间范围: %s ~ %s\n", startTime, endTime)
	fmt.Println("   滚动窗口（1小时间隔）:")
	tumblingWindow.Reset()
	i := 0
	for tumblingWindow.Next() {
		i++
		fmt.Printf("   窗口 %d: %s ~ %s\n", i, tumblingWindow.Start(), tumblingWindow.End())
	}
	fmt.Println()

	fmt.Println("3. 窗口数据聚合")
	baseTime := time.Date(2024, 12, 25, 10, 0, 0, 0, time.UTC)
	records := make(record.Records, 0, 12)

	temperatures := []struct {
		offset time.Duration
		value  float64
	}{
		{0 * time.Minute, 22.5},
		{15 * time.Minute, 23.1},
		{30 * time.Minute, 23.8},
		{45 * time.Minute, 24.2},
		{60 * time.Minute, 24.5},
		{75 * time.Minute, 24.3},
		{90 * time.Minute, 23.9},
		{105 * time.Minute, 23.5},
		{120 * time.Minute, 23.2},
		{135 * time.Minute, 22.9},
		{150 * time.Minute, 22.7},
		{165 * time.Minute, 22.5},
	}

	for _, temp := range temperatures {
		r := record.GetRecord()
		r["timestamp"] = baseTime.Add(temp.offset)
		r["temperature"] = temp.value
		records = append(records, r)
	}

	fmt.Println("   原始温度数据（每15分钟）:")
	for _, r := range records {
		fmt.Printf("   %s: %.1f°C\n", r["timestamp"], r["temperature"])
	}
	fmt.Println()

	aggWindow := time.NewTumblingWindow(baseTime, baseTime.Add(3*time.Hour), time.Hour)
	results, err := time.AggregateByWindow(records, "timestamp", "temperature", aggWindow, "avg")
	if err != nil {
		fmt.Printf("聚合失败: %v\n", err)
	} else {
		fmt.Println("   按小时平均温度:")
		for _, res := range results {
			fmt.Printf("   %s ~ %s: %.1f°C\n", res.WindowStart, res.WindowEnd, res.Value)
		}
	}

	for _, r := range records {
		r.Release()
	}

	fmt.Println()
	fmt.Println("=== 时序数据处理示例完成！===")
}
```

这段代码展示了 sfsDb 的完整时序数据处理功能：

1. **时间粒度格式化**：使用 `FormatTimeByGranularity()` 按不同粒度格式化时间
2. **时间信息获取**：使用 `IsWeekday()`、`IsWeekend()`、`GetQuarter()`、`GetWeekNumber()` 获取时间信息
3. **时间戳转换**：在 `time.Time` 和 Unix 时间戳之间转换
4. **滚动窗口**：使用 `NewTumblingWindow()` 创建滚动窗口
5. **滑动窗口**：使用 `NewSlidingWindow()` 创建滑动窗口
6. **窗口数据聚合**：使用 `AggregateByWindow()` 对窗口内数据进行聚合

## 14.2 时序数据概述

时序数据是工业物联网和边缘计算场景中的重要数据类型。时序数据具有以下特点：

- **时间有序**：数据按时间顺序产生和存储
- **高写入频率**：传感器数据等通常以高频产生
- **批量查询**：通常查询某段时间范围内的数据
- **数据聚合**：需要按时间窗口进行统计分析

sfsDb 提供专门的 time 包来处理时序数据。

### 14.4.2 滚动窗口

**示例代码**（来自 `time/window.go`）：

```go
// TumblingWindow 滚动窗口实现
type TumblingWindow struct {
    startTime    time.Time
    endTime      time.Time
    windowSize   time.Duration
    currentStart time.Time
}

// NewTumblingWindow 创建一个新的滚动窗口
func NewTumblingWindow(startTime, endTime time.Time, windowSize time.Duration) *TumblingWindow {
    return &amp;TumblingWindow{
        startTime:    startTime,
        endTime:      endTime,
        windowSize:   windowSize,
        currentStart: startTime,
    }
}
```

滚动窗口的特点是窗口之间不重叠，适用于按固定时间间隔聚合数据。

## 14.5 时间序列数据压缩

### 14.5.1 压缩算法介绍

time 包支持两种时序数据压缩算法：

1. **Delta编码（增量编码）**：通过存储连续值之间的差异来压缩数据，适合值变化较小的时序数据
2. **Run-Length Encoding (RLE，游程编码)**：通过存储重复值及其计数来压缩数据，适合有连续重复值的时序数据

### 14.5.2 压缩示例

**示例代码**（来自 `time/compression.go`）：

```go
// CompressTimeSeries 压缩时间序列数据
func CompressTimeSeries(points []TimeSeriesPoint, compressionType string, interval time.Duration) (*CompressedTimeSeries, error) {
    if len(points) == 0 {
        return nil, nil
    }

    // 如果未指定时间间隔，自动计算
    if interval == 0 && len(points) > 1 {
        interval = points[1].Time.Sub(points[0].Time)
    }

    var compressedValues []byte

    switch compressionType {
    case "delta":
        compressedValues = compressDelta(points)
    case "rle":
        compressedValues = compressRLE(points)
    default:
        compressedValues = compressDelta(points) // 默认使用delta编码
    }

    return &CompressedTimeSeries{
        StartTime:       points[0].Time,
        Interval:        interval,
        CompressedValues: compressedValues,
        CompressionType:  compressionType,
    }, nil
}
```

### 14.5.3 压缩使用示例

```go
// 创建测试数据点
var points []sfsTime.TimeSeriesPoint
now := time.Now()
for i := 0; i < 10; i++ {
    points = append(points, sfsTime.TimeSeriesPoint{
        Time:  now.Add(time.Duration(i) * time.Minute),
        Value: float64(i),
    })
}

// 压缩时间序列数据
compressed, err := sfsTime.CompressTimeSeries(points, "delta", time.Minute)
if err != nil {
    panic(err)
}

// 解压缩时间序列数据
decompressed, err := sfsTime.DecompressTimeSeries(compressed, 10)
if err != nil {
    panic(err)
}

// 计算压缩率
originalSize := len(points) * 16 // 假设每个点16字节
compressedSize := len(compressed.CompressedValues)
compressionRatio := sfsTime.GetCompressionRatio(originalSize, compressedSize)
fmt.Printf("压缩率: %.2f\n", compressionRatio)
```

### 14.5.4 压缩算法选择

- **Delta编码**：适合值变化较为平滑的时序数据（如温度、湿度等传感器数据）
- **RLE编码**：适合有大量重复值的场景（如状态监控数据）
