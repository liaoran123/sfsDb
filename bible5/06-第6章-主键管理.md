# 第 4 章：主键管理

## 4.1 单主键

主键是数据库表中用于唯一标识每条记录的字段。sfsDb 支持单主键和复合主键两种模式。

### 创建单主键表

```go
// 创建单主键表
userTable, err := engine.TableNew("user_table")
if err != nil {
    panic(err)
}

// 设置字段
userFields := map[string]any{
    "id":   0,     // 主键字段
    "name": "",    // 普通字段
    "age":  0,     // 普通字段
}
err = userTable.SetFields(userFields)
if err != nil {
    panic(err)
}

// 创建单主键索引
pk, err := engine.DefaultPrimaryKeyNew("pk_id")
err = pk.AddFields("id")
err = userTable.CreateIndex(pk)
if err != nil {
    panic(err)
}
```

### 使用示例

```go
// 插入数据
user := map[string]any{
    "id":   1,
    "name": "Alice",
    "age":  25,
}
id, err := userTable.Insert(&user)
if err != nil {
    panic(err)
}
fmt.Printf("插入成功，ID: %v\n", id)

// 主键查询
searchData := map[string]any{"id": 1}
iter, err := userTable.Search(&searchData)
if err != nil {
    panic(err)
}
defer iter.Release()

records := iter.GetRecords(true)
defer records.Release()

for _, record := range records {
    fmt.Printf("记录: %v\n", record)
}
```

**代码来源**：`docs/zh/advanced/primary_key.md`、`engine/table_test.go`

## 4.2 复合主键

复合主键使用多个字段组合唯一标识一条记录。

### 创建复合主键表

```go
// 创建复合主键表
orderTable, err := engine.TableNew("order_table")
if err != nil {
    panic(err)
}

// 设置复合主键字段
orderFields := map[string]any{
    "order_id": 0,     // 复合主键字段1
    "user_id":  0,     // 复合主键字段2
    "product":  "",    // 普通字段
    "quantity": 0,     // 普通字段
}
err = orderTable.SetFields(orderFields)
if err != nil {
    panic(err)
}

// 创建复合主键索引
compositePk, err := engine.DefaultPrimaryKeyNew("pk_order_user")
if err != nil {
    panic(err)
}
// 添加多个主键字段
compositePk.AddFields("order_id", "user_id")
err = orderTable.CreateIndex(compositePk)
if err != nil {
    panic(err)
}
```

### 插入复合主键记录

```go
// 插入复合主键记录
order := map[string]any{
    "order_id": 1,
    "user_id":  100,
    "product":  "商品A",
    "quantity": 2,
}
_, err = orderTable.Insert(&order)
if err != nil {
    panic(err)
}
```

### 复合主键查询

```go
// 复合主键查询
searchOrder := map[string]any{
    "order_id": 1,
    "user_id":  100,
}
iter, err := orderTable.Search(&searchOrder)
if err != nil {
    panic(err)
}
defer iter.Release()

records := iter.GetRecords(true)
defer records.Release()

for _, record := range records {
    fmt.Printf("订单记录: %v\n", record)
}
```

**代码来源**：`docs/zh/advanced/primary_key.md`、`engine/table_test.go`

#### EdgeX 物联网数据示例（包含字符串复合主键）

下面是一个实际的工业物联网场景示例，使用 `deviceName`（字符串）和 `timestamp`（时间戳）作为复合主键：

**代码来源**：`engine/table_edgex_test.go:13-217`

```go
package main

import (
	"fmt"
	"os"
	"time"

	"github.com/liaoran123/sfsDb/engine"
	"github.com/liaoran123/sfsDb/storage"
)

func main() {
	dbPath := "./edgex_readings_db"
	os.RemoveAll(dbPath)
	defer os.RemoveAll(dbPath)

	_, err := storage.GetDBManager().OpenDB(dbPath)
	if err != nil {
		panic(err)
	}
	defer storage.GetDBManager().CloseDB()

	// 创建 EdgeX 读数表
	table, err := engine.TableNew("edgex_readings")
	if err != nil {
		panic(err)
	}

	// 设置字段，deviceName 是字符串类型
	fields := map[string]any{
		"id":         "",
		"deviceName": "",    // 字符串类型
		"reading":    "",
		"value":      0.0,
		"valueType":  "",
		"baseType":   "",
		"timestamp":  int64(0),
		"metadata":   "",
	}
	table.SetFields(fields)

	// 创建复合主键：deviceName + timestamp
	primaryKey, err := engine.DefaultPrimaryKeyNew("pk_device_time")
	if err != nil {
		panic(err)
	}
	primaryKey.AddFields("deviceName", "timestamp")
	table.CreateIndex(primaryKey)

	// 关键步骤：为字符串字段指定长度
	// 由于 deviceName 是字符串类型，必须指定固定长度
	fieldTypeLen := map[string]uint8{
		"deviceName": 7,  // 固定长度为7个字符
	}
	table.GetfieldTypeLen(&fieldTypeLen)

	// 创建其他索引
	deviceNameIndex, err := engine.DefaultNormalIndexNew("idx_deviceName")
	if err != nil {
		panic(err)
	}
	deviceNameIndex.AddFields("deviceName")
	table.CreateIndex(deviceNameIndex)

	timestampIndex, err := engine.DefaultNormalIndexNew("idx_timestamp")
	if err != nil {
		panic(err)
	}
	timestampIndex.AddFields("timestamp")
	table.CreateIndex(timestampIndex)

	// 插入测试数据
	baseTime := time.Now()
	testData := []map[string]any{
		{
			"id":         "reading001",
			"deviceName": "dev0001",  // 长度必须为7个字符
			"reading":    "temperature",
			"value":      25.5,
			"valueType":  "Float64",
			"baseType":   "Number",
			"timestamp":  baseTime.UnixNano(),
			"metadata":   `{"unit": "°C"}`,
		},
		{
			"id":         "reading002",
			"deviceName": "dev0001",
			"reading":    "temperature",
			"value":      26.2,
			"valueType":  "Float64",
			"baseType":   "Number",
			"timestamp":  baseTime.Add(1 * time.Minute).UnixNano(),
			"metadata":   `{"unit": "°C"}`,
		},
		{
			"id":         "reading003",
			"deviceName": "dev0002",
			"reading":    "count",
			"value":      1024.0,
			"valueType":  "Int64",
			"baseType":   "Number",
			"timestamp":  baseTime.UnixNano(),
			"metadata":   `{"unit": "count"}`,
		},
	}

	for i, item := range testData {
		deviceName := item["deviceName"].(string)
		if len(deviceName) != 7 {
			panic(fmt.Sprintf("第 %d 条数据 deviceName 长度错误: 期望7, 实际%d", i+1, len(deviceName)))
		}

		_, err := table.Insert(&item)
		if err != nil {
			panic(fmt.Sprintf("插入第 %d 条数据失败: %v", i+1, err))
		}
	}

	fmt.Println("✓ 数据插入成功！")
	fmt.Println()

	// 复合主键查询
	fmt.Println("1. 复合主键查询（deviceName + timestamp）")
	searchFields := map[string]any{
		"deviceName": "dev0001",
		"timestamp":  testData[0]["timestamp"],
	}
	dataIter, _ := table.Search(&searchFields)
	defer dataIter.Release()
	records := dataIter.GetRecords(true)
	defer records.Release()
	for _, record := range records {
		fmt.Printf("   找到记录: %v\n", record)
	}
	fmt.Println()

	// deviceName 索引查询
	fmt.Println("2. deviceName 索引查询")
	searchDevice := map[string]any{
		"deviceName": "dev0001",
	}
	deviceIter, _ := table.Search(&searchDevice)
	defer deviceIter.Release()
	deviceRecords := deviceIter.GetRecords(true)
	defer deviceRecords.Release()
	fmt.Printf("   找到 %d 条记录\n", len(deviceRecords))
	fmt.Println()
}
```

#### 字符串复合主键的关键要点：

1. **必须指定固定长度**：字符串字段用于复合主键时，必须通过 `GetfieldTypeLen()` 方法指定固定长度
2. **数据长度一致性**：所有插入数据的该字段长度必须与指定长度一致
3. **表结构更新**：如果表结构更新，需要调用 `ResetFieldTypeLen()` 重置字段类型长度映射
4. **长度验证**：在插入数据前，应该验证字符串字段长度是否符合要求

## 4.3 主键自动创建机制

当表中没有显式创建主键时，sfsDb 会在首次需要主键时自动创建一个默认主键。

### 自动创建机制

这个机制由 `GetPrimaryKey()` 方法实现：

```go
// 获取主键索引
func (t *Table) GetPrimaryKey() PrimaryKey {
    pk := t.indexs.getPrimaryKey()
    if pk == nil {
        //没有主键，需要创建一个默认主键。
        //所以主键必须在表未有数据前创建。
        pk, _ = DefaultPrimaryKeyNew("id")
        pk.AddFields("id")
        t.CreateIndex(pk)
    }
    return pk
}
```

**工作原理**：
1. 当调用 `GetPrimaryKey()` 方法时，系统会首先检查表是否已有主键
2. 如果没有主键，系统会自动创建一个名为 "id" 的默认主键
3. 默认主键会添加 "id" 字段作为主键字段
4. 然后将这个默认主键索引添加到表中
5. 最后返回创建的主键索引

**注意事项**：
- 系统注释明确指出："所以主键必须在表未有数据前创建。"
- 这意味着如果表中已经有数据，再调用需要主键的操作时，可能会导致数据不一致
- 因此，建议在表创建后、插入数据前，显式设置主键

**使用场景**：
- 快速原型开发，暂时不需要自定义主键
- 简单应用，使用默认的自增 ID 作为主键即可满足需求

### 索引创建顺序的重要性

在添加索引时，系统会执行 `createIndexData` 函数来为现有数据创建索引数据，该函数会调用 `GetPrimaryKey()` 方法：

```go
// 对table现有数据创建对应的新索引数据
func (t *Table) createIndexData(index Index) error {
    //排除主键
    if index == t.GetPrimaryKey() {
        return nil
    }
    //根据主键前缀遍历所有数据，创建索引数据
    //获取主键前缀
    pk := t.GetPrimaryKey() // 这里会触发自动创建主键
    pkPrefix := pk.Prefix(t.id)
    slice := util.NewRangeHelper(pkPrefix).FromComparison(util.Like, pkPrefix)
    //pkPrefix创建迭代器
    iter := t.kvStore.Iterator(slice.Start, slice.Limit)
    defer GlobalTableIterPool.Put( iter)
    //遍历所有数据
    var value []byte
    for iter.Next() {
        _, value = iter.Key(), iter.Value()
        rval, err := pk.Parse(t.fieldsid, value)
        if err != nil {
            return err
        }
        if rval == nil {
            continue
        }
        indexValue := pk.GetID(rval)
        switch index := index.(type) {
        case NormalIndex:
            idxvalueofkey := index.Join(rval)
            idxkey := index.JoinPrefix(t.id, idxvalueofkey)
            t.kvStore.Put(idxkey, indexValue)
        case FullTextIndex:
            //func (c *batchContainer) Operation 函数基本一样
            fieldsBytes, err := pk.Parse(t.fieldsid, value)
            if err != nil {
                return err
            }
            if fieldsBytes == nil {
                continue
            }
            joinValues := index.JoinFullValues(fieldsBytes, t.id)
            defer util.PutBytesArray(joinValues)
            for _, joinValue := range joinValues {
                if joinValue == nil {
                    continue
                }
                // 为全文索引创建索引数据
                t.kvStore.Put(joinValue, indexValue)
            }
        }
    }
    return nil
}
```

### 重要建议

1. **先添加主键，后添加其他索引**：如果在添加其他索引之前没有显式创建主键，系统会在执行 `createIndexData` 时自动创建一个默认主键
2. **避免自动创建主键**：自动创建的主键可能不符合你的业务需求，建议始终显式创建主键
3. **在数据插入前设置主键**：确保在插入任何数据之前设置好主键，以避免数据不一致

## 4.4 主键最佳实践

### 选择主键字段

- **选择唯一、稳定的字段**：主键字段应该是唯一的且不经常变化的
- **避免使用敏感信息**：不要使用身份证号、手机号等敏感信息作为主键
- **使用自增 ID**：对于大多数应用，使用自增整数作为主键是个好选择

### 复合主键注意事项

- **组合主键限制**：组合主键只支持固定长度类型的组合
- **字符串类型处理**：字符串字段用于复合主键时，必须通过 `GetfieldTypeLen()` 方法指定固定长度
- **数据一致性**：所有插入数据的字符串主键字段长度必须与指定长度一致
- **表结构更新**：如果表结构更新，需要调用 `ResetFieldTypeLen()` 重置字段类型长度映射
- **字段顺序**：主键字段的顺序会影响查询性能，应将最常用的字段放在前面

### 性能考虑

- **主键大小**：主键字段越小，索引占用空间越小，查询性能越好
- **避免频繁更新主键**：主键更新会导致所有相关索引都需要更新，影响性能
